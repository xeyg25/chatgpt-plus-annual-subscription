## 官方每月 20 美元，为什么第三方价格更高？

这是比较 ChatGPT Plus 年付方案时最值得算清楚的一笔账。

OpenAI 官方 Plus 标价为每月 20 美元。如果按 12 个月简单计算，理论上的官方月付总额是 240 美元，但这只是数学上的累计金额，并不代表 OpenAI 提供 240 美元的年付套餐。官方目前仍按月收费。

第三方平台的价格通常会高于官方标价，原因可能包括：

- 支持人民币或本地支付方式；
- 平台代为处理支付和订阅流程；
- 需要承担支付通道、汇率和售后成本；
- 可能提供失败退款或人工客服；
- 多月套餐中包含一定的服务溢价；
- 收银台可能使用港币或其他币种结算。

WildAI 的帮助文档明确提到，收银台金额可能显示为港币，最终应以付款页面的实际金额为准。平台也说明价格会因为上游收单、汇率或供应变化而调整，不能把旧文章中的价格当成当前报价。

因此，判断是否划算，应该用下面这个公式：

> 实际每月成本 = 最终支付金额 ÷ 有效月份数

例如页面显示一个多月套餐时，不要只看总价。把总价除以有效月份，再和官方每月 20 美元比较。如果你有可用的国际信用卡，直接官方订阅通常更便宜；如果你没有合适支付方式，愿意为本地付款和代办流程支付服务费，第三方方案才有实际价值。

## 通过 WildAI 订阅前，最需要注意什么？

### 1. 需要提交敏感的账号会话信息

WildAI 的 ChatGPT 教程要求用户在已经登录 ChatGPT 的浏览器中打开会话接口，复制一段 JSON 信息并提交到平台。Pro 相关教程还提到可能需要复制 ChatGPT Cookie。

这类信息虽然不一定等同于账号密码，但可能具有较高的账号访问权限。平台文档也提醒用户不要把凭证发给其他人，仅用于本次开通。

购买前至少要确认：

- 你提交的是自己的账号；
- 没有把密码、验证码或支付信息一并提交；
- 操作完成后及时退出其他设备；
- 不要在陌生电脑或公共浏览器中获取会话信息；
- 如果账号出现异常登录、订阅异常或强制退出，立即检查账号安全设置；
- 不要把 Cookie 或 Session JSON 保存到聊天记录、网盘或公开代码仓库。

如果你无法接受将会话信息交给第三方，就不适合使用这种代订阅方式。官方渠道虽然支付门槛可能更高，但账号凭证不会经过代办平台。

### 2. 价格和有效期以当前页面为准

第三方平台的优惠和价格可能变化很快。搜索结果中能够看到一些旧文章列出过 ChatGPT Plus 的单月、两个月和三个月参考价格，但这些数字不是当前官方定价页稳定展示的内容，也没有足够依据证明今天仍然有效。

因此，不建议根据搜索引擎中的旧表格直接付款。进入购买页后，重点核对：

- 选的是 ChatGPT Plus 还是 Pro；
- 订阅时长是多少；
- 是一次性单月，还是长期连续订阅；
- 总付款金额是多少；
- 平均每月成本是多少；
- 是否存在自动续费；
- 是否需要后续手动操作；
- 失败、未开通或账号异常时如何退款。

页面提供的推广入口带有 `ACCPAY` 参数，但本文无法从公开页面确认它对应的具体折扣金额、适用套餐和有效期限。因此，不能把它写成固定的“八折”“立减多少元”或“全年最低价”。打开页面后，以结算页实际显示为准。

### 3. 不要把 Plus 和 API 混为一谈

ChatGPT Plus 是面向 ChatGPT 网页端、桌面端或移动端的订阅。它不包含 OpenAI API 余额，也不能自动给开发者项目增加 API 调用额度。

WildAI 的帮助文档也明确说明，ChatGPT Plus 与 OpenAI API 是两个独立的计费项目，平台目前提供的是会员订阅代充，不提供官方 API 额度充值。

如果你的需求是：

- 在网页里对话；
- 使用更高等级的模型；
- 上传文件；
- 生成图片；
- 使用深度研究、项目或自定义 GPT；
- 使用与 Plus 关联的部分开发工具；

那么你关注的是 ChatGPT Plus 或 Pro。

如果你的需求是：

- 在自己的程序里调用模型；
- 为网站或应用接入 API；
- 按调用量计费；
- 管理 API Key 和开发者账单；

那你应该单独查看 OpenAI API 的官方计费页面，不能购买 Plus 代替 API。

1. 官方月付累计成本；
